🤖 Bot Telegram chạy ngay trong trang này

Chỉ cần file index.html — không cài gì thêm. Bot hoạt động khi tab này đang mở.

  1. Dán token → bấm Bật bot. Lần đầu sẽ hiện mã 6 số (muốn thêm người dùng bot thứ hai: bấm Mã ghép nối mới).
  2. Mở Telegram, nhắn cho bot: /start 123456 (mã vừa hiện) → bot ghép nối tài khoản của bạn.
  3. Xong! Bấm 🛒 Tạo đơn mới trong Telegram. Đơn hiện ở web ngay.

⚠️ Nếu báo không gọi được Telegram: nhiều nhà mạng ở Việt Nam chặn Telegram → bật VPN rồi bấm Bật bot lại. Token lưu trong trình duyệt này — đừng chia sẻ file sao lưu. Mỗi bot chỉ bật được ở MỘT thiết bị (nên là máy tính luôn mở trang này); các máy khác chỉ cần kết nối GitHub ở tab ☁️ để xem và chốt đơn. Điện thoại hay tự tắt tab nền nên không hợp chạy bot.

⚡ Dùng trong Telegram

  1. Bấm 🛒 Tạo đơn mới → chạm sản phẩm (chạm lại để tăng số lượng) → ➖ ➕ chỉnh số lượng.
  2. Chọn 👤 Khách, 📞 SĐT, 🏢 MST, 🎁 Giảm giá nếu cần; chọn thanh toán 💵 🏦 💳 📱.
  3. Bấm ✅ XUẤT HÓA ĐƠN → bot gửi hóa đơn chữ → chạm vào hóa đơn để sao chép → dán gửi khách.
  4. Đơn tự vào Lịch sử và Doanh thu trên web.

☁️ Lưu database lên GitHub

Đơn hàng, sản phẩm, ghi chú, doanh thu được lưu thành 1 file JSON trong repo Private của bạn. Máy / điện thoại nào nhập cùng thông tin dưới đây sẽ thấy y hệt dữ liệu, tự cập nhật khoảng 20 giây một lần (đơn mới từ bot Telegram cũng vậy).

Nâng cao

📲 Kết nối nhanh máy khác

Đang kết nối ở máy này → bấm Copy mã → sang điện thoại dán vào ô dưới.

⚠️ Mã kết nối chứa token — chỉ gửi cho chính bạn, đừng đăng ở đâu cả. Token Telegram không được đưa lên GitHub.

🧭 Cài đặt (làm 1 lần, ~3 phút)

  1. Vào github.com/new → đặt tên (VD pos-data) → chọn Private → Create repository.
  2. Vào github.com/settings/personal-access-tokens/new (Fine-grained token):
    • Repository access → Only select repositories → chọn repo vừa tạo.
    • Permissions → Repository permissions → Contents → Read and write.
    • Bấm Generate token → copy chuỗi github_pat_….
  3. Dán token + tên-github/pos-data vào bên trái → Kết nối & đồng bộ. File dữ liệu tự được tạo.
  4. Điện thoại / máy khác: mở trang này → dán mã kết nối (hoặc nhập 2 ô trên) → thấy toàn bộ đơn.

Cách hoạt động: mỗi lần bạn (hoặc bot) tạo / xoá đơn, trang tự đẩy lên GitHub sau ~1 giây và kéo thay đổi của máy khác về. Hai máy sửa cùng lúc sẽ được trộn lại, không mất đơn nào; đơn đã xoá ở máy này sẽ biến mất ở máy kia. Mất mạng vẫn dùng bình thường, có mạng lại tự đồng bộ.

Để trang chạy trên điện thoại: đặt index.html vào một repo công khai riêng (không chứa dữ liệu) và bật GitHub Pages → mở link đó trên mọi máy. Repo dữ liệu vẫn để Private. Hoặc cứ gửi file index.html qua Zalo cho điện thoại và mở bằng trình duyệt.

Dữ liệu trong repo là chữ thường (JSON) nên ai có quyền vào repo đều đọc được — hãy để Private và không thêm người lạ.
