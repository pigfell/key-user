🤖 Trạng thái bot Telegram

🚀 Cài đặt (làm 1 lần)

  1. Cài Node.js bản LTS (nodejs.org).
  2. Để index.html, bot.js, start.bat chung một thư mục.
  3. Trên Telegram mở @BotFather → /newbot → copy token.
  4. Bấm đúp start.bat (hoặc chạy node bot.js). Lần đầu nó tạo file config.json → dán token vào ô "token" → chạy lại.
  5. Cửa sổ đen hiện mã 6 số. Nhắn cho bot: /start 123456 để ghép nối tài khoản của bạn.
  6. Luôn mở web bằng http://localhost:3000 (đừng mở file trực tiếp) để đơn từ bot tự hiện ở đây.

Bot chạy ở cửa sổ đen nên không cần mở web vẫn nhận và tạo đơn; chỉ cần máy đang bật và cửa sổ đó không đóng. Muốn chạy 24/7 thì đem bot.js lên VPS/máy chủ riêng.

⚠️ Nếu trạng thái báo không kết nối được Telegram: nhiều nhà mạng ở Việt Nam chặn Telegram → bật VPN, hoặc điền "proxy" trong config.json (VD http://127.0.0.1:10809).

⚡ Dùng trong Telegram

  1. Bấm 🛒 Tạo đơn mới → chạm sản phẩm (chạm lại để tăng số lượng) → nút ➖ ➕ chỉnh số lượng.
  2. Chọn 👤 Khách, 📞 SĐT, 🏢 MST, 🎁 Giảm giá nếu cần; chọn thanh toán 💵 🏦 💳 📱.
  3. Bấm ✅ XUẤT HÓA ĐƠN → bot gửi hóa đơn chữ → chạm vào hóa đơn để sao chép → dán gửi khách.
  4. Đơn tự vào Lịch sử và Doanh thu trên web.
